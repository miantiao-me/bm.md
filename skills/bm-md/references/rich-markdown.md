# 图片尺寸与文本高亮

只在用户明确给出尺寸、布局确需固定尺寸或局部结论需要强调时使用这些语法。完成 Markdown 后交给 bm.md `render`，检查生成结果。

## 设置图片尺寸

只设置宽度：

```markdown
![编辑器预览界面|320](https://example.com/editor.png)
```

同时设置宽高：

```markdown
![编辑器预览界面|320x180](https://example.com/editor.png)
```

遵守以下规则：

- 宽和高只写正整数；宽高之间使用小写 `x`，不要写大写 `X`。
- 不添加 `px` 或其他单位。
- bm.md 渲染时会从图片 `alt` 和题注中剥离尺寸后缀；上例的替代文本仍为“编辑器预览界面”。
- 不知道合适尺寸时使用普通图片：`![编辑器预览界面](https://example.com/editor.png)`。
- `alt` 应准确描述图片内容；纯装饰图留空为 `![](url)`，不要为图片捏造信息。

## 高亮重点

使用闭合的双等号标记局部重点：

```markdown
渲染前必须先 ==检查事实与结构==。

这是 ==**必须执行的检查**==，这是 ==_需要留意的条件_==。

已废弃内容可写为 ==~~旧参数~~==，也可写为 ~~==已撤回的重点==~~。
```

遵守以下规则：

- 标记必须闭合，开头的 `==` 后不能紧跟空白。
- 不在行内代码或块级代码中使用高亮语法。
- 只高亮局部关键结论、限制或动作，不要整段刷高亮。
- 粗体、斜体和删除线嵌套时保持各自标记完整。
- 高亮不能替代标题、列表或警告正文；先保证内容结构清晰。
