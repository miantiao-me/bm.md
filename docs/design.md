# UI 设计系统

本文档阐述 bm.md 的视觉语言、交互原则与界面组件规范。

---

## 设计哲学

bm.md 是一款面向高频输入的专业级排版工具，视觉与交互围绕以下三大原则展开：

1. **工程化与低装饰（Utilitarian & Minimal）**：界面呈现克制、沉静的工具气质。杜绝为追求视觉效果而加入的彩色渐变、大面积弥散阴影或发光效果；控件边界清晰，最大化留出编辑与预览的核心视区。
2. **直角美学（Crisp Geometry）**：虽然系统主题底层定义了多级圆角变量，但常规矩形控件（按钮、输入框、卡片、弹窗面板、标签页等）统一采用直角（`rounded-none`）。这一特征是刻意建立的工业化视觉标识，仅天然圆形元素（如头像、状态指示点）使用全圆角（`rounded-full`）。
3. **严格的无障碍对比度（WCAG AA）**：所有文本与背景配对均经过严格计算，确保对比度达到 4.5:1 以上，交互焦点环（Focus Ring）对背景对比度不低于 3:1。

## 页面框架与空间布局

### 整体布局结构

系统采用全屏工作区布局（高度固定为 `100dvh`，杜绝引起移动端视口跳动的 `100vh`），由三大区域组成：

```
┌─────────────────────────────────────────────────────────────┐
│  [📄 文档一 ✕] [📄 文档二 ✕] [+]               顶部文件标签栏 │
├─────────────────────────┬───────────────────────────────────┤
│                         │                                   │
│                         │                                   │
│       CodeMirror 6      │            实时预览视窗           │
│        Markdown         │                                   │
│         编辑器          │      ┌─────────────────┐          │
│                         │      │   设备模拟框    │          │
│                         │      │ (iPhone/Safari) │          │
│                         │      └─────────────────┘          │
│                         │                                   │
├─────────────────────────┴───────────────────────────────────┤
│  [编辑器操作]           bm.md           [预览器与导出操作]   │
│  导入/导出/格式化/设置   (关于)         复制/画板/主题/自定义CSS│
└─────────────────────────────────────────────────────────────┘
```

### 空间与交互规则

- **可调节分屏**：左右两侧默认各占 50% 宽度，支持拖拽中央分隔条实时调整占比。
- **最小宽度保护**：编辑区与预览区各自限制最小宽度为 512px，整体视口最小支持宽度约为 1024px，确保高密度工具界面的可用性。
- **顶部文件标签栏**：
  - 高亮标注当前会话激活的文件；
  - 双击标签文本或聚焦后按下 `F2` 即可原地重命名；
  - 点击 `×` 或聚焦后按 `Delete` 键关闭文件；
  - 文档正文异步加载期间设有加载门禁（显示骨架状态），严禁在正文未就绪前接受编辑或用旧内容导出。
- **固定底栏（48px 高度）**：
  - **左侧 EditorActionBar**：文档导入、导出 Markdown、分隔线、代码格式化、命令面板入口、编辑器设置。
  - **居中**：bm.md 标识（点击呼出关于弹窗）。
  - **右侧 PreviewerActionBar**：复制微信、复制 HTML、导出菜单（JPEG/PNG/PDF/打印）、分隔线、排版样式、代码主题、Mermaid 图表主题、Infographic 信息图设置、自定义 CSS 弹窗。

## 色彩体系

界面采用现代 OKLCH 色彩空间，基于 [Ayu](https://github.com/ayu-theme/ayu-colors) 主题进行语义化适配：

### 浅色模式（Ayu Light 深度调优）

针对长时间文字编辑场景，系统对标准 Ayu Light 进行了对比度加固：

| 语义 Token           | 说明          | 对应色值 / OKLCH                    | 无障碍设计要点                                                     |
| :------------------- | :------------ | :---------------------------------- | :----------------------------------------------------------------- |
| `background`         | 主背景底色    | `#fcfcfc` / `oklch(0.98 0.004 264)` | 极淡蓝灰，降低纯白刺眼感                                           |
| `foreground`         | 正文文字      | `#5c6166` / `oklch(0.44 0.02 264)`  | 对背景对比度达 6.2:1                                               |
| `primary`            | 强调主色      | `#c77618` / `oklch(0.64 0.14 62)`   | 由原版 `#f29718` 加深，作为焦点环对背景达 3:1                      |
| `primary-foreground` | 主色上的文字  | `oklch(0.2 0.05 62)`                | **采用深色文字**，对比度达 5.22:1（避免原版浅白字对比度仅 2.51:1） |
| `secondary`          | 次级色面      | `#f8f9fa` / `oklch(0.96 0.005 264)` | 用于次级按钮或辅助背景                                             |
| `muted-foreground`   | 弱化辅助字    | `oklch(0.52 0.02 264)`              | 对背景对比度达 4.6:1，严格满足 AA                                  |
| `destructive`        | 危险操作/错误 | `#e65050` / `oklch(0.61 0.18 25)`   | 搭配深色文字，满足 4.5:1 对比度                                    |
| `success`            | 成功反馈      | `#6cbf43` / `oklch(0.72 0.17 136)`  | 搭配深色文字，满足 4.5:1 对比度                                    |

## 编辑与预览环境设计

### CodeMirror 编辑器

- **结构与标尺**：左侧紧贴柔和行号标尺，当前行以极低透明度高亮。
- **高对比光标**：光标采用主色 Accent，打字停顿失焦时保持清晰定位。
- **滚动条体验**：编辑器纵向滚动条采用细线模式（6px 宽），仅在光标悬停于编辑区域时平滑显现，阅读正文时自动隐匿，杜绝视觉干扰。

### 设备模拟视窗

预览内容放置在真实模拟容器中，直观反映终端阅读体验：

#### 1. 移动端视图（iPhone 模拟框）

- **尺寸比例**：外壳固定宽度 415px，内层内容视口 375px，左右边框各 20px。
- **高度弹性**：根据屏幕可视区域在 650px 至 850px 间自动扩展。
- **特征装饰**：顶部内嵌比例精准的灵动岛装饰模块，真实还原微信移动端沉浸式阅读效果。

#### 2. 桌面端视图（Safari 模拟框）

- **尺寸比例**：最大宽度限制为 768px，居中呈现。
- **特征装饰**：顶部配备 Safari 风格的极简控制条，左侧放置三个中性窗口圆点，中央地址栏显示 `bm.md` 标识。

### 预览区侧边工具栏

位于预览区右侧边缘，采用 Lucide 矢量图标并配有 Tooltip 提示，纵向分为三组：

1. **外观与显示**：系统亮暗模式切换、移动端预览切换、桌面端预览切换、预览视窗独立配色方案切换。
2. **内建扩展**：MCP 协议配置弹窗、AI Skill 技能说明弹窗。
3. **外部生态**：REST API 在线文档、Twitter、GitHub 仓库、赞助渠道。

## 浮层、面板与交互规范

### 全局命令面板（Cmd/Ctrl + K）

- **即时检索**：输入关键字模糊匹配所有可用动作。
- **分级收拢**：排版样式、代码高亮主题、Mermaid 主题与信息图主题以二级子菜单呈现，避免主列表过长。
- **纯内存控制**：命令面板的状态不进行本地持久化，关闭后即刻重置。

### 自定义 CSS 弹窗

- **安全命名空间**：界面显著提示所有样式规则必须挂载在 `#bm-md` 根节点下。
- **显式保存机制**：文本框输入时不直接干扰预览，只有在用户点击“保存”按钮后才进行样式编译与持久化存储。

### 动效与性能约束

- **严禁布局属性动效**：严格禁止对 `width`、`height`、`margin`、`padding`、`top`、`left` 施加 CSS 过渡或动画，杜绝重排（Reflow）引发的卡顿。
- **仅限合成器属性**：允许的动画仅限于 `transform` 与 `opacity`。
- **短促响应**：微交互动效时长不得超过 200ms；进入动画统一使用 `ease-out`。
- **无障碍优先**：系统全面监听 `prefers-reduced-motion`，在用户开启减弱动态效果时自动关闭非必要动画。
