# 前端 UI 与交互工程准则

本文档梳理 bm.md 在界面组件、交互行为、样式设计与动效层面的核心工程约束，供团队协同与界面开发参考。

---

## 技术栈与样式体系

- **优先使用预设规范**：在引入自定义数值前，优先使用 Tailwind CSS 与 shadcn/ui 的默认间距、圆角与阴影层级。
- **动画库选型**：需要 JavaScript 驱动的复杂动画时使用 `motion/react`；常规页面入场与微动效优先使用 `tw-animate-css`。
- **类名合并**：所有动态条件类名统一使用 `cn()`（基于 `clsx` 与 `tailwind-merge`）进行合并，避免样式冲突。

---

## 组件与无障碍（A11y）

- **无障碍交互原语**：涉及键盘焦点、浮层定位或弹出菜单的组件，必须基于可靠的无障碍原语系统（优先使用 `@base-ui/react`，其次为 `React Aria`）。
- **原语系统一致性**：同一个交互表面（Surface）内严禁混用不同的底层原语系统。
- **原生行为保护**：除非产品有明确说明，不得手动编写非标准的自定义焦点或键盘捕获逻辑。
- **纯图标可访问性**：所有仅包含图标的按钮或可交互元素，必须显式声明 `aria-label` 属性以供屏幕阅读器读取。

---

## 交互设计要求

- **破坏性操作保护**：对于删除文档、重置内容等不可逆或破坏性操作，必须使用 `AlertDialog` 弹窗进行二次确认。
- **视口高度规范**：严禁使用引起移动端地址栏伸缩抖动的 `h-screen`，统一采用动态视口单位 `h-dvh`（或 `100dvh`）。
- **安全边距适配**：页面固定定位元素必须适配视口安全边距（`safe-area-inset`）。
- **就近错误提示**：操作校验失败或网络异常信息应就近展示在触发控件旁，避免使用与操作上下文脱离的远端提示。
- **尊重原生编辑行为**：严禁在 `input` 或 `textarea` 等编辑元素中阻止用户的系统粘贴行为。
- **加载状态表达**：根据上下文选择紧凑的局部文字、进度指示或骨架屏，避免非必要的全屏遮罩。

---

## 动效与性能边界

- **克制使用动效**：界面动效只服务于明确的层级转场与操作反馈，无明确需求时不添加装饰性动效。
- **仅限合成器属性**：动画属性严格限定于浏览器 GPU 合成器支持的 `transform` 与 `opacity`；严禁对 `width`、`height`、`top`、`left`、`margin`、`padding` 等触发布局重排（Reflow）的属性添加动效。
- **绘制属性限制**：避免对 `background` 或 `color` 添加大面积过渡，仅允许用于文本与图标等小型局部元素。
- **时长与缓动曲线**：交互反馈动画时长不得超过 200ms；入场动效统一使用 `ease-out`；非必要不引入复杂的自定义贝塞尔曲线。
- **无障碍优先**：系统必须严格遵从用户的 `prefers-reduced-motion` 系统偏好，在开启时禁用非必要过渡。
- **避免性能瓶颈**：严禁对大面积 `blur()` 或 `backdrop-filter` 背景层施加动画；严禁在持续活动的动画之外滥用 `will-change`；离屏动画必须及时暂停。

---

## 排版与布局

- **数据对齐**：表格、统计数值与版本号等并列数据，必须使用等宽数字（`tabular-nums`）排版。
- **文本溢出控制**：高密度空间内的文本必须配置 `truncate` 或 `line-clamp` 防溢出处理。
- **字符间距控制**：除非特定标题设计明确要求，不得随意调整字符间距（`tracking-`），以避免跨平台字体渲染引擎引起意外折行。
- **分层刻度系统**：`z-index` 必须严格使用项目中已规划的固定层级阶梯，禁止使用任意值（如 `z-[9999]`）。
- **正方形尺寸简写**：对于宽高相等的元素，优先使用 `size-*` 简写，而非重复声明 `w-* h-*`。

---

## 视觉与色彩约束

- **零渐变原则**：界面控件与面板背景严格采用扁平中性色面，禁止使用多色或紫色渐变。
- **低装饰性阴影**：优先使用项目默认的阴影系统，杜绝厚重的彩色阴影或漫反射光晕。
- **明确的操作指引**：任何列表或文档的空状态（Empty State），必须提供清晰的下一步操作按钮或指引文案。
- **单一视觉焦点**：每个视图或操作区域内，同时呈现的强调色（Primary）主要操作原则上仅限一个。
